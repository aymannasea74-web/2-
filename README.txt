مكتبة العمال - طريقة التشغيل
1) ارفع محتوى المجلد كاملاً إلى أي استضافة (مثل GitHub Pages أو Netlify أو استضافتك) على رابط HTTPS.
2) افتح الرابط من الهاتف مرة واحدة مع الإنترنت، ثم اختر "إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق".
3) بعدها يعمل بدون إنترنت، وتبقى البيانات محفوظة في الهاتف.
4) لتحويله إلى ملف APK يمكنك استخدام pwabuilder.com بإدخال رابط الموقع.
تنبيه: البيانات خاصة بمتصفح الهاتف، فاستخدم زر "نسخ احتياطي" داخل البرنامج بشكل دوري.
الملفات: index.html (البرنامج) | manifest.webmanifest | sw.js (للعمل بدون إنترنت) | icon-192.png و icon-512.png
